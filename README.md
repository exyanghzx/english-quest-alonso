# English Quest de Alonso

Versión oficial y pública del curso personal de inglés de Alonso.

## Cómo publicar cambios

1. Editar los archivos dentro de `dist/`.
2. Revisar el sitio localmente.
3. Enviar los cambios a la rama `main`.
4. GitHub Pages publica automáticamente la nueva versión.

El progreso del estudiante se guarda en el navegador mediante `localStorage`; no se sube al repositorio.
